# После MVP

1. Проверка на реальных Windows 10/11 и нескольких IMAP/SMTP-провайдерах; исправления совместимости по результатам.
2. Подгрузка старых писем и инкрементальная загрузка тел без повторного получения MIME.
3. Ручной выбор нестандартных папок, улучшение CID-картинок и MIME edge cases.
4. Развернуть подготовленный Mail OAuth broker на `oauth.morfius.ru` и проверить живой Mail flow; реализовать OAuth Microsoft. Google OAuth сейчас работает в режиме Testing только для Test users. Перед публичным релизом: перевести приложение в In Production, проверить требования verification для Gmail scope, подготовить Branding / Privacy Policy / описание назначения доступа и проверить вход внешних пользователей без ручного добавления в Test users.
5. Подпись Windows installer и обновления приложения.

Не расширять приложение календарём, задачами, AI и другими функциями вне почты.
