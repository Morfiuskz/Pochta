# Ручная проверка на Windows

Использовать отдельный тестовый ящик. Не добавлять пароли в репозиторий или отчёты.

- [ ] Установить NSIS artifact, открыть приложение, проверить WebView2 и масштабирование 100/125/150%.
- [ ] Добавить два ящика: TLS 993/465 и STARTTLS 143/587. Проверить независимые SMTP login/password и общий режим.
- [ ] «Проверить подключение»: успешный вход; неверный пароль; неправильный hostname/порт; недоступная сеть; недоверенный сертификат.
- [ ] Проверить записи `com.morfius.mail` в Windows Credential Manager. В SQLite/config нет паролей.
- [ ] Перезапустить: аккаунты и локальный кэш появляются до сети; синхронизация запускается автоматически.
- [ ] Отправить в тестовый ящик текст, HTML с картинкой, MIME-вложение и кириллическую тему; обновить и прочитать.
- [ ] Сравнить read/unread и star с веб-почтой, включая изменение флагов в веб-почте и повторный sync.
- [ ] Удалить письмо: появилось в корзине сервера, остальные помеченные Deleted письма не удалены общим EXPUNGE.
- [ ] Поиск по имени, email, теме и слову в теле; кириллица; вкладки unread/attachments и выбор аккаунта.
- [ ] Новое письмо: отправитель по умолчанию, смена отправителя, To/Cc, два вложения; получатель реально получил письмо.
- [ ] Reply и Reply All: Reply-To, удаление собственных адресов/дубликатов, Re:, цитата, In-Reply-To.
- [ ] Закрыть compose: локальный черновик доступен после перезапуска; отправить его; убедиться, что исчез из drafts.
- [ ] Открыть HTML с script, onerror, iframe, form, CSS url: активного содержимого нет, картинка не загружается до кнопки.
- [ ] Скачать вложение через native dialog, отменить скачивание, проверить содержимое сохранённого файла.
- [ ] Переименовать аккаунт: email/login/server/password неизменны. Отключить/включить, сменить default.
- [ ] Удалить аккаунт: cache/drafts и vault entries удалены, серверные письма остались.
- [ ] Закрыть приложение при недоступной сети, запустить без интернета: чтение/поиск кэша доступны, сетевые ошибки понятны.

До выполнения этого списка с настоящим ящиком нельзя считать доставку через конкретного провайдера и Windows Credential Manager проверенными end-to-end.
