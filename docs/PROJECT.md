# Проект

Morfius Mail — личный локальный Windows-клиент нескольких почтовых аккаунтов. Интерфейс на русском, desktop-first, dark navy/violet, sidebar → список → просмотр письма.

MVP: ручное подключение IMAP/SMTP, TLS/STARTTLS/None, проверка подключения, пресеты провайдеров, отображаемое имя аккаунта, отправитель по умолчанию, включение/отключение/удаление, синхронизация, локальный поиск, фильтры, HTML/text, вложения, read/unread, star, удаление в корзину, compose, Reply/Reply All и локальные черновики.

Вне scope: POP3, календарь, задачи, контакты, AI, RSS, чат, правила, шаблоны, IDLE/push, сложная система провайдеров. OAuth2 отложен.
