# Privacy Policy

«Почта» — open-source desktop-приложение, которое подключается напрямую к выбранным пользователем почтовым провайдерам по IMAP/SMTP и OAuth.

## Какие данные обрабатываются

- Письма, их metadata, вложения, локальные черновики и поисковый индекс кэшируются на устройстве пользователя в локальной базе данных приложения.
- Пароли и OAuth-токены хранятся в системном secure credential storage отдельно от почтового кэша.
- Локальный кэш не имеет дополнительного шифрования поверх механизмов защиты операционной системы.

Письма не отправляются разработчику. Приложение не продаёт пользовательские данные и не использует их для рекламы или аналитики.

## OAuth и Mail broker

Яндекс и Google OAuth взаимодействуют с соответствующими провайдерами. Данные Google используются только для функций почтового клиента: входа, получения и отправки почты, синхронизации состояния и обновления OAuth-доступа.

Для Mail.ru используется HTTPS broker на `oauth.morfius.ru`, потому что Mail token endpoint требует Client Secret, который нельзя безопасно встраивать в desktop-приложение. Broker только выполняет token exchange с Mail.ru, не использует базу данных и не хранит письма, access tokens, refresh tokens или authorization codes. Чувствительные значения проходят через память broker только на время запроса.

## Внешнее содержимое

HTML писем очищается перед показом. Удалённые изображения заблокированы по умолчанию и загружаются только после явного действия пользователя; при их загрузке внешний сервер может получить обычные сетевые данные запроса, включая IP-адрес.

## Удаление локальных данных

Удаление аккаунта из приложения удаляет связанные локальные данные и сохранённые credentials этого аккаунта. Все данные приложения также можно удалить средствами Windows или удалением каталога данных приложения после его закрытия. Отзыв OAuth-разрешения у провайдера выполняется отдельно в настройках соответствующего аккаунта.

Ни одно программное обеспечение не может гарантировать абсолютную безопасность. О проблемах безопасности сообщайте согласно [SECURITY.md](SECURITY.md).
